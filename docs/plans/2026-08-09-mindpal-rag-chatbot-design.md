# MindPal — RAG Chatbot Design

**Date:** 2026-08-09
**Status:** Approved

## Overview

MindPal is a standalone RAG (Retrieval-Augmented Generation) chatbot for students at `/my/mindpal`. Admin uploads PDF books/resources, the system chunks and embeds the text, and students can ask questions in a chat interface. Answers are generated by AI based on facts from the uploaded sources, with page-level citations.

## Architecture

| Layer | Detail |
|-------|--------|
| **Student Route** | `/my/mindpal` — Inertia React (student portal) |
| **Admin Route** | `/admin/mindpal` — Livewire Volt (admin dashboard) |
| **AI Provider** | OpenAI — GPT-4o-mini (chat) + text-embedding-3-small (embeddings) |
| **Vector Storage** | MySQL/SQLite — `mindpal_chunks` table with JSON embedding column |
| **PDF Processing** | `smalot/pdfparser` — extract text, chunk by ~500 tokens with 50 token overlap |
| **Background Jobs** | Laravel Queue — PDF processing + embedding generation |

## RAG Pipeline

### Ingestion (Admin Upload)
1. Admin uploads PDF via `/admin/mindpal`
2. Document record created with status `processing`
3. Queued job: extract text from PDF using smalot/pdfparser
4. Split text into chunks (~500 tokens each, 50 token overlap, preserve page boundaries)
5. Generate embeddings for each chunk via OpenAI text-embedding-3-small
6. Store chunks + embeddings in `mindpal_chunks`
7. Update document status to `ready`

### Retrieval (Student Question)
1. Student types question in chat at `/my/mindpal`
2. Generate embedding for question via OpenAI
3. Cosine similarity search against all chunk embeddings → top 5 most relevant
4. Build prompt: system instruction + retrieved chunks (with source metadata) + question
5. Send to GPT-4o-mini with streaming enabled
6. Stream response to student via SSE (Server-Sent Events)
7. Save message with source references (document title, page number)

## Pages

### Student — `/my/mindpal` (Inertia React)
- **Sidebar**: Conversation list (recent chats), "New Chat" button
- **Main area**: Chat interface with message bubbles
- **Features**:
  - Streaming AI responses (token-by-token via SSE)
  - Source citations in answers ("Berdasarkan *Book Title*, halaman 23...")
  - Conversation history (resume old chats)
  - Mobile-responsive (sidebar collapses)

### Admin — `/admin/mindpal` (Livewire Volt)
- **Document list**: Title, status badge (processing/ready/failed), page count, chunk count, upload date
- **Upload**: Drag-and-drop or file picker, PDF only, max 50MB
- **Actions**: Delete document (cascade deletes chunks), re-process failed
- **Stats**: Total documents, total chunks, total student conversations

## Key Features

- **Streaming response**: SSE (EventSource) for real-time token-by-token display
- **Source citations**: Every answer includes references to source document + page
- **Conversation memory**: Students can continue old conversations
- **Background processing**: PDF chunking + embedding via Laravel Queue jobs
- **Cost tracking**: tokens_used per message for OpenAI cost monitoring
- **Rate limiting**: Max 50 messages/hour per student

## Tech Stack

| Package | Purpose |
|---------|---------|
| `openai-php/laravel` | OpenAI API client for Laravel |
| `smalot/pdfparser` | PHP library for PDF text extraction |

## Security

- Student access: `auth` + student role middleware
- Admin access: `auth` + `role:admin` middleware
- Rate limiting: 50 messages/hour per student (throttle middleware)
- PDF validation: mime type `application/pdf`, max 50MB
- No plaintext API keys — stored in `.env` as `OPENAI_API_KEY`

## Access Control

- All logged-in students can access all documents (no enrollment-based filtering)
- Admin-only upload and management
- Each student has their own private conversation history
